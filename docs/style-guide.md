# ISHIDUE AI アバター スタイルガイド

役員AIアバターの画風仕様。**羊毛フェルト人形風（needle-felted wool doll）** に統一する。

この仕様は既存の `ceo.jpg` と `secretary.jpg` の2枚から逆算したもの。この2枚が唯一の「正」であり、
迷ったときは仕様文よりも実物2枚を優先すること。

---

## 1. 画材・質感（最重要）

このスタイルの本質は「**実写の背景の前に、羊毛フェルトで作った人形が立っている写真**」であること。
人形部分だけがフェルト、背景は実写。ここを取り違えると全く別の絵になる。

| 要素 | 仕様 |
|---|---|
| 技法 | ニードルフェルト（羊毛フェルト）の手作り人形 |
| 肌 | 圧縮された羊毛の質感。毛羽立ちがうっすら見える。ツヤはなく完全なマット |
| 髪 | 羊毛の繊維の流れが束として見える。毛先に細い繊維のほつれ |
| 衣服 | フェルト生地。編み目・起毛が肉眼で分かるスケール感 |
| 縫製 | 小物の縁に手縫いのステッチが見える |
| 輪郭 | 繊維がわずかに逆光で光る「毛のハロー」が出る |
| 禁止 | プラスチック的なツヤ、CG的なサブサーフェス、粘土（クレイ）的な滑らかさ、ぬいぐるみ的な省略 |

**クレイアニメ風ではない。** 粘土は表面が滑らかで繊維がない。フェルトは繊維が主役。

## 2. 顔の作り

- 頭部はやや大きめ（人形的なプロポーション）だが、頭身は極端にデフォルメしない
- 目は**リアル寄り**。虹彩・瞳孔・キャッチライトを描き込む。ここだけは写実性を残すのがこの画風の要
- 眉・まつげは繊維で植毛したように見せる
- 表情は穏やか。口を大きく開けて笑わせない（`secretary` の軽い笑みが上限）
- 実在の人物に似せない。役職ごとの「人物像」に留める

## 3. 小物：ぶどうロゴのフェルトPC

2枚とも共通で持っている、シリーズの識別要素。**必ず入れる。**

- ノートPCを開いた状態で、片手で軽く支えて胸の高さでカメラ側に向ける
- 天板がカメラ正面を向き、ロゴが読める角度
- 素材：ライトグレーのフェルト。四辺に手縫いのステッチが一周
- ロゴ：**ぶどうの房**。房の粒はフェルトのボール、上部に葉と蔓。天板よりわずかに濃いグレーで、
  平面プリントではなく**浮き彫り（レリーフ）**として立体的に付いている
- ロゴは単色グレー。色を付けない

## 4. 背景

- **実写写真**。フェルト化しない
- 浅い被写界深度で大きくボケさせる（人形だけがピント面）
- 内容：都市のオフィス街。左手前にガラス張りのビルのファサードが斜めに奥へ抜ける。
  右手に緑の植栽。奥に高層ビル群と明るい曇り空
- ボケ光源（白〜暖色の丸ボケ）を数点入れる
- 全体トーンは寒色寄りのグリーングレー

## 5. ライティング

- 曇天の自然光。柔らかく拡散した順光〜半逆光
- 硬い影・強いコントラストは作らない
- 人形に軽いリムライトが乗り、繊維の毛羽が光る

## 6. 構図・画角

- バストアップ（胸から上）。人形は画面中央〜やや右
- PCは画面右下に配置
- アスペクト比は **ほぼ正方形〜わずかに縦長**（1:1 〜 1:1.15）
  - 実測: `ceo` 1816×1744 (1.04:1)、`secretary` 1740×1534 (1.13:1)

## 7. カラーパレット

シリーズ共通の色域。役職ごとの服の色はこの範囲から選ぶ。

| 用途 | 色 |
|---|---|
| 主役色 | くすんだグリーン（オリーブ〜モスグリーン） |
| 副色 | グレー、生成り（クリーム）、タン |
| 背景 | グリーングレー、ガラスの青灰色 |
| 小物 | ライトグレー（PC）、ダークグレー（ロゴ） |

彩度の高い色・原色は使わない。

## 8. 共通プロンプトブロック

画像生成に渡す共通部分。役職ごとの被写体記述と合成して使う。
このテキストの正本は [`prompts/_base.md`](../prompts/_base.md) にあり、
`scripts/build_prompts.py` が被写体記述と合成して `prompts/out/<role>.txt` を生成する。

生成手順は [`prompts/README.md`](../prompts/README.md) を参照。

## 9. 現状の統一状況

| 役職 | 現ファイルの画風 | 対応 |
|---|---|---|
| `ceo` | フェルト風 | 基準。そのまま |
| `secretary` | フェルト風 | 基準。そのまま |
| `cfo` `chro` `clo` `cmo` `coo` `cso` `cto` | 実写風ヘッドショット | **フェルト風で作り直しが必要** |

7名は画風が違うため、最終的には全て差し替える。
差し替えまでの間、既存の実写画像は「その人物の顔・髪型・服装の参照元」として使う
（`prompts/subjects/*.md` の記述はここから抽出している）。

## 10. 既存ファイルの既知の問題

作り直し時に持ち込まないよう注意。

| ファイル | 問題 |
|---|---|
| 全9枚 | 拡張子は `.jpg` だが中身は **PNG (RGBA)**。実体と不一致 |
| `chro.jpg` | 右下に別画像のサムネイルが写り込んでいる（スクショ由来） |
| `cmo.jpg` | 左下に UI の「ステム設定」という文字が写り込んでいる |
| `cso.jpg` | 左下に黒い点（UI要素の切れ端） |

拡張子の不一致は、外部から `raw.githubusercontent.com` 経由で参照されている可能性があるため
今回は改名していない。改名する場合は参照元の有無を確認してから行うこと。
