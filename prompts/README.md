# プロンプトの使い方

## ファイル構成

```
prompts/
├── _base.md          共通スタイルブロックの正本（全役職で共有）
├── subjects/         役職ごとの被写体記述（人物の特徴だけを書く）
│   ├── ceo.md
│   └── ...
└── out/              生成物。_base.md + subjects を合成したコピペ用プロンプト
    ├── ceo.txt
    └── ...
```

`out/` は**手で編集しない**。編集しても次回の生成で上書きされる。

## アバターを作る

1. `prompts/out/<role>.txt` を開く
2. `=== PROMPT ===` 以下を画像生成ツールのプロンプト欄に貼る
3. `=== NEGATIVE PROMPT ===` 以下をネガティブプロンプト欄に貼る
   （ネガティブ欄がないツールの場合は、この行は使わない）
4. 出力を `docs/style-guide.md` の仕様と `ceo.jpg` / `secretary.jpg` の実物と見比べて確認
5. 合格したら `<role>.jpg` を差し替え、`avatars.json` の `style` を `felt`、
   `status` を `current` に更新する

### 確認時のチェックポイント

作り直しで最も失敗しやすい順に並べてある。

- [ ] **繊維が見えるか**（クレイ／プラスチック／ぬいぐるみになっていない）
- [ ] **目だけは写実的か**（虹彩・瞳孔・キャッチライトがある）
- [ ] **ぶどうロゴのフェルトPC**を持っているか。ロゴがレリーフになっているか
- [ ] **背景が実写でボケているか**（背景までフェルト化していない）
- [ ] アスペクト比がほぼ正方形（1:1 〜 1:1.15）
- [ ] 彩度が抑えられ、シリーズのパレットに収まっているか
- [ ] UI の写り込み・透かし・文字が入っていないか
- [ ] 実在の人物に似ていないか

## プロンプトを編集する

編集する場所は 2 つだけ。

| 変えたいもの | 編集するファイル |
|---|---|
| 全員に効く画風・背景・小物・禁止事項 | `prompts/_base.md` |
| 特定の人物の髪型・表情・服装 | `prompts/subjects/<role>.md` |

編集後は必ず再生成する。

```bash
python3 scripts/build_prompts.py
```

`_base.md` の `## STYLE` / `## NEGATIVE` という見出しはスクリプトが目印にしているので変更しない。
`subjects/*.md` の `## SUBJECT` も同様。

## 生成物が最新か確認する

```bash
python3 scripts/build_prompts.py --check
```

ソースと `out/` がずれていれば、ずれているファイル名を出して終了コード 1 を返す。

## アバターを追加する

1. `avatars.json` の `avatars` に 1 件追加する（`role` が ID になる）
2. `prompts/subjects/<role>.md` を作り、`## SUBJECT` セクションに被写体記述を書く
3. `python3 scripts/build_prompts.py` を実行する
